# Saumya Shree — Portfolio Site

Personal portfolio website for Saumya Shree, built for GitHub Pages.

## Live Site

Visit: [https://000v000.github.io/portfolio-site-saumya/](https://000v000.github.io/portfolio-site-saumya/)

## Setup

1. Go to repository **Settings** → **Pages**
2. Set source to **Deploy from a branch** → `main` / `/ (root)`
3. Save — site will be live in a few minutes

## Customization

- Update LinkedIn URL in `index.html` (search for `linkedin.com`)
- Update email in `index.html` (search for `mailto:`)
- Replace `assets/profile.png` with a new profile photo
